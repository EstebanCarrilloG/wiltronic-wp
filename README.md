# Wiltronic-WP

**Wiltronic-WP** es un proyecto web desarrollado utilizando **HTML**, **CSS**, y **jQuery**, que me permitió explorar conceptos clave como el uso de objetos en JavaScript, la implementación de animaciones al hacer scroll, y la conexión con datos almacenados en un archivo de Excel. Este proyecto es un ejemplo práctico de cómo se pueden construir interfaces interactivas y dinámicas con tecnologías del lado del cliente.

## 🎯 Objetivo del proyecto

El objetivo principal de **Wiltronic-WP** fue aprender y practicar:

- El manejo de **objetos en JavaScript**.
- La implementación de **animaciones al hacer scroll** para mejorar la experiencia de usuario.
- La manipulación de datos desde una base externa, utilizando un archivo de Excel como base de datos.

## 🚀 Tecnologías utilizadas

- **HTML**: Estructura del contenido del sitio.
- **CSS**: Diseño y estilo visual del sitio.
- **jQuery**: Simplificación de la manipulación del DOM y creación de efectos dinámicos.
- **JavaScript**: Manejo de objetos y lógica de interacción.
- **Excel como base de datos**: Almacenamiento y consulta de información para el proyecto.

## 🌟 Características principales

1. **Animaciones al hacer scroll**: 
   - Elementos que aparecen o cambian su estilo a medida que el usuario navega por la página.
   
2. **Interactividad con jQuery**: 
   - Uso de eventos como clics y desplazamientos para dinamizar el contenido.
   
3. **Uso de objetos en JavaScript**:
   - Implementación de estructuras de datos organizadas para gestionar la lógica del sitio.

4. **Consulta de datos desde Excel**:
   - Lectura y uso de información almacenada en un archivo de Excel para alimentar el contenido dinámico.

## 📂 Estructura del proyecto

```plaintext
Wiltronic-WP/
├── index.html        # Página principal del proyecto.
├── styles.css        # Archivo CSS para los estilos.
├── scripts.js        # Lógica de interacción y manejo de objetos.
├── data.xlsx         # Archivo de Excel utilizado como base de datos.
└── assets/           # Carpeta para imágenes y otros recursos.
```

## 📖 Aprendizajes clave

A través de este proyecto, adquirí experiencia en:

- La importancia de trabajar con objetos en JavaScript para organizar datos y lógica de forma eficiente.
- Cómo las animaciones y transiciones al hacer scroll pueden mejorar la interacción con el usuario.
- Métodos para integrar y manipular datos de una fuente externa como un archivo de Excel.
- Desarrollo de sitios dinámicos utilizando **HTML**, **CSS**, y **jQuery**.
